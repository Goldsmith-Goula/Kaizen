# **App Name**: Kaizen

## Core Features:

- Dashboard: Dashboard view to display top 3 priority tasks, a progress summary, and a motivational element.
- Task Manager: Task manager with calendar view, drag and drop interface, status tracking and recurring tasks.
- Financial Dashboard: Financial dashboard to visualize budget creation, transaction logging and financial goals.
- Habit Tracker: Daily streak tracking with "Don't break the chain" style visualization to help users build consistent habits.
- Progress Visualization: Heat map calendar providing a GitHub-style activity visualization for task completion, allowing users to easily identify trends and track their progress over time.
- Milestone Tracking: Mark and celebrate key achievements, providing positive reinforcement and motivation for continued progress.
- Self-Discipline Score: Calculate a score based on task completion rates and habit streaks, providing a quantifiable measure of self-discipline and progress.
- Reporting: Auto-generated summaries of progress on a weekly and monthly basis, providing users with insights into their performance and areas for improvement.
- "Future Self" Builder: Define who you want to become across various categories, including values, skills, finances, relationships, career, and health.
- Progress Journal: Reflection log with timestamps and mood tracking (emoji selection) to record thoughts, feelings, and insights related to personal development.
- Budgeting & Finance: Create budgets, log transactions, and track financial goals, empowering users to manage their finances effectively and achieve financial well-being.
- App Customization: App themes, dashboard customization, notification preferences and data export/import to backup and restore functionality (JSON export/import)
- UX Enhancements: Subtle animations, tooltips, keyboard shortcuts, gesture controls, and a clear visual hierarchy to enhance the user experience and make the app more intuitive and efficient to use.

## Style Guidelines:

- Primary color: Dark blue (#0E1A2B) for a calm and focused environment.
- Secondary color: Light gray (#E5E7EB) for content and backgrounds.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clear, sans-serif fonts optimized for readability on all devices.
- Use consistent and minimalist icons from Lucide-React.
- Clean and organized layout using Tailwind CSS grid and flexbox.
- Subtle animations using Framer Motion for smooth transitions and feedback.
